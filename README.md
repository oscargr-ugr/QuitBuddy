# Descrpición del problema
Numerosos conocidos de diferentes grupos de edades me han expresado que  enfrentan diariamente la indecisión sobre qué ropa usar. Esto depende de múltiples factores como el clima, las actividades programadas, el estilo personal, y la disponibilidad de prendas limpias. La frustración aumenta cuando no tienen tiempo para pensar en su atuendo o no cuentan con una herramienta que les ayude a decidir.
